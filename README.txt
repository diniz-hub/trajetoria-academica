# Trajetória Acadêmica — site de apresentação

## Como visualizar
1. Extraia o arquivo ZIP.
2. Abra `index.html` em um navegador atualizado. Para evitar limitações de alguns navegadores ao carregar recursos locais, você também pode abrir a pasta com uma extensão de servidor local.

## Personalizações
- Link do vídeo: procure `https://youtube.com/shorts/5yJiqz5Qxs8?is=owI4kDPGLZYBaIhE` em `index.html` e substitua pelo link definitivo, se necessário.
- Imagens: os arquivos usados estão na pasta `assets/`.
- O nome do professor orientador não foi informado no material textual; o site mantém o rótulo “Professor orientador” sem inventar um nome.
- A miniatura do YouTube depende de conexão com a internet. Se não carregar, o botão para abrir o vídeo continua disponível.

## Arquivos
- `index.html`: estrutura e conteúdo
- `style.css`: layout responsivo, cores e modo claro/escuro
- `script.js`: menu móvel, tema salvo, animações, galeria ampliada e botão voltar ao topo
\nAtualização: a seção Demonstração contém player incorporado do YouTube e link direto para abrir o vídeo. O botão Tema alterna entre modo claro e escuro, com preferência salva no navegador.\n

DOWNLOAD DO APLICATIVO:
O arquivo app-debug.apk fica na mesma pasta do index.html. O botão 'Baixar aplicativo (Android)' do site aponta para esse arquivo. Publique a pasta completa para manter o download funcionando.
